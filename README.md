What I've learned / thoughts:

- Have had a great learning experience using modules & classes, and using import and export syntax - I feel like I am gaining a good understanding of how application modules, and classes should be organised.
- I become frustrated with how many queryselectors, and DOM manipulation lines of code are needed to code the layout, and believe this is where something like React would excel.
- Realised I should have written a renderScreen method within ScreenController to collate all render-type methods, rather than have them spread throughout other methods.
- Due to a lack of time available for this project, it spanned far too great a time-period, thus I hastily cobbled the remainder of it together with less regard for clean code.
- ScreenController was breaking the "Single Responsibility" design principle in multiple areas, it could have been organised far better.
- Gained a-lot more practice with DOM manipulation.
- Unfortunately had to retire the Note functionality due to lack of time.
